# YOLOv8 o'zi nima?!

![alt text](https://raw.githubusercontent.com/ultralytics/assets/refs/heads/main/yolo/performance-comparison.png "yolo models")

<p style="text-align: justify">Assalomu alaykum qadrli do’stlar! YOLOv8 (You Only Look Once version 8) bu o'zi nima, suvmi okeanmi, sho'rvami o'zi nima? Bugun shu haqida gaplashamiz. YOLOv8- bu YOLO oilasiga mansub obektlarni aniqlash (object detection) uchun ishlatiladigan algoritm. Ultralytics tomonidan ishlab chiqilgan, ushbu post yozilayotgan davrda eng ommobop computer vision algoritmlardan biri hisoblanadi(YOLOv9, YOLOv10, YOLO11 chiqgan, lekin hali yolov8 kabi ommobop emas). Ushbu algoritm o'zining bir nechta takrorlanmas xususiyatlari bilan mashxurlikka erishdi, birinchidan o'rnatishga juda qulay, sohadagi asosiy vazifalarni yechish uchun mo'ljallangan, yani obektlarni aniqlash, tasvirlarni tanish, tasvirlarni segmentatsiya qilish, obektlarni kuzatish (object tracking). Eng muhimi, open source dataset larda eng yaxshi natijalarni berdi. Tezlik va aniqlik bilan ishlashda yolov8 eng yaxshi deb topildi. 
Keling yolov8 ni o'rnatish, hamda obetklarni aniqlashda ishlatib ko'ramiz.
<br>O'rnatish juda oson (pip orqali) </p>

```bash
pip install ultralytics
```
<p style="text-align: justify">
Tamom! Hamma narsa ishga tayyor! YOLO to'g'ridan to'g'ri CLI (Commond line interface) orqali ham ishlatish mumkin:
</p>

```bash
yolo predict model=yolov8n.pt source='https://ultralytics.com/images/bus.jpg'
```
<p style="text-align: justify">
Yoki Python script orqali ham:
</p>

```python
from ultralytics import YOLO

# Load a model
model = YOLO("yolov8n.pt")

# Perform object detection on an image
results = model("https://ultralytics.com/images/bus.jpg")
results[0].show()

```
<p style="text-align: justify">
Yolov8 modellar obektlarni aniqlash, segmentatsiya uchun  COCO dataset da o'qitilgan (pretrained models), tasvirlarni klassifikatsiya qilish uchun esa ImageNet dataset da o'qitilgan
Quyidagi rasmda esa Yolov8 modelllari imkoniyatlari misollarda ko'rsatilgan. 
</p>
![alt text](https://raw.githubusercontent.com/ultralytics/assets/main/im/banner-tasks.png "banner tasks")




Yolov8 modellar arxitektura jihatdan ham bir nechta turlarga bo'linadi, yani:

[YOLOv8l](https://github.com/ultralytics/assets/releases/download/v8.2.0/yolov8l.pt),

<p style="text-align: justify">
n va s (nano and small) modellar tezlik jixatdan yuqori, hamda resource tomondan kichik bo'lganligi sabab edge device (jetson nano kabi qurilmalar) lar uchun ishlatiladi. m, l, x (medium, large, extra large) modellar esa server solution (server yechimlar) uchun, chunki bu arxitekturalr aniqlik jixatdan yaxshiroq biroq ko'proq resource talab qiladi. Qisqa qilib aytganda, sizga aniqlik muhim bo'lsa katta modellarni, tezlik muhim bo'lsa kichik modellarni ishlatisihingiz mumkin. 
<br> Bugunga shular, keyingi postlarimda yolov8 ni real world proektlarda ishlatib ko'ramiz. Stay tuned! Chao!
</p>
